
### Robots.txt

Текущий robots.txt (генерируется Next.js) — проверить что отдаётся. Добавить:

```
User-agent: *
Allow: /

User-agent: Yandex
Host: vladen-crimea.ru

Disallow: /api/
Disallow: /admin/

Sitemap: https://vladen-crimea.ru/sitemap.xml
```

**Важно**: в проекте нет `[locale]` сегмента (структура `app/page.tsx`, не `app/[locale]/page.tsx`), значит Вариант А — `app/sitemap.ts` и `app/robots.ts` в Next.js работают корректно. Статические файлы в `public/` не нужны.

Проверка после деплоя:
```bash
curl -I https://vladen-crimea.ru/sitemap.xml   # ожидаем application/xml
curl -I https://vladen-crimea.ru/robots.txt    # ожидаем text/plain
```

### Понизить приоритет /modular

`/modular` сейчас `priority: 0.9` — страницы нет в шапке (убрали). Снизить до 0.5 или убрать из sitemap, чтобы не тратить краулерный бюджет.
