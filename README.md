# Vladen — сайт строительной компании с AI-ассистентом

Продакшен-сайт строительной компании (Крым) с **встроенным AI-ассистентом на базе Claude**, который консультирует посетителей, помогает с расчётом и захватывает заявки в Telegram. Реальное внедрение, работает в проде: **[vladen-crimea.ru](https://vladen-crimea.ru)**

---

## Что делает AI-ассистент

- **Консультирует** посетителей по услугам компании (строительство домов, инженерные сети, ремонт) на естественном языке — на базе Claude (`@anthropic-ai/sdk`).
- **Ведёт к заявке**: помогает прикинуть параметры через калькулятор и мягко доводит до контакта.
- **Захватывает лид**: имя + телефон (с валидацией) + данные калькулятора + история диалога **уходят владельцу в Telegram** мгновенно — ни одно обращение не теряется, даже когда никто не на телефоне.

Бизнес-эффект: сайт не просто «визитка», а канал, который сам отвечает и собирает заявки 24/7.

## Архитектура

```
Посетитель → ChatWidget (React) → /api/chat (Claude) → диалог
                                 → /api/telegram → заявка владельцу (имя, телефон, расчёт, диалог)
```

- **ChatWidget** — клиентский виджет чата, изолированный UI.
- **/api/chat** — серверный роут, общается с Claude, держит системный контекст компании.
- **/api/telegram** — приём лида, валидация телефона, отправка через Telegram Bot API; токены — только в env на сервере.

## Стек

`Next.js (App Router)` · `React` · `TypeScript` · `Tailwind CSS` · `Framer Motion` · `GSAP` · `Lenis` · `@anthropic-ai/sdk (Claude)` · `Telegram Bot API`

## Особенности реализации

- Серверные роуты для AI и Telegram — **секреты не попадают в клиент** (только env).
- Mobile-first, плавный скролл (Lenis) и анимации (GSAP / Framer Motion) без ущерба скорости.
- Захват лида устойчив: валидация телефона, передача контекста диалога и расчёта вместе с заявкой.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить ключи (см. ниже)
npm run dev
```

Переменные окружения:

```
ANTHROPIC_API_KEY=...      # ключ Claude для /api/chat
TELEGRAM_BOT_TOKEN=...     # бот для доставки заявок
TELEGRAM_CHAT_ID=...       # чат/получатель заявок
```

> 🔒 Реальные ключи в репозиторий не коммитятся.

## Ограничения

- Системный контекст ассистента заточен под одну компанию (не multi-tenant).
- Медиа (видео) хранятся в репозитории — для прод-масштаба лучше вынести на CDN.
